## Instructions

- When writing documentation, link to existing sources and the [Szótár](README.md#szótár) for concepts.
- Avoid modifying already written text in existing documentation (ask for permission). Rather than appending to existing files (unless expanding an existing list), append the documentation with a new file and link to it whenever possible.
- Instruct the user to contact component owners BEFORE making modifications to multiple components!
- Use and highlight the [patterns](./docs/patterns.md) in planning and implementation.
