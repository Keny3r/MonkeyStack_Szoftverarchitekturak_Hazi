## Architektúrális minták

A feladat részeinek megoldásához és tervezéséhez az alábbi minták használata és kiemelése erősen javasolt:

1. Szolgáltatáshozzáférés és -konfiguráció
    - Wrapper Facade
    - Component Configurator
    - Interceptor
    - Extension Interface
2. Eseménykezelés
    - Reactor
    - Proactor
    - ACT
    - Acceptor-Connector
3. Konkurenciakezelés
    - Active Object
    - Monitor Object
    - Half Sync / Half Async
    - Leader-Followers
    - Thread-Specific Storage
4. Szinkronizáció
    - Scoped Locking
    - Strategized Locking
    - Thread-Safe Interface
    - Double-Checked Locking Optimization
